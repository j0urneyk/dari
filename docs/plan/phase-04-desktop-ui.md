# Phase 4 — gpui-kit 데스크톱 UI

## 목표

일반 사용자가 앱 하나로 "내 화면 공유"와 "원격 접속"을 할 수 있는 GUI를 완성한다.

## 설계

- 앱 구조: gpui-kit `Root` 아래 홈 창 1개 + 원격 세션마다 뷰어 창 1개.
  앱 시작 시 tokio 런타임을 별도 스레드 풀로 만들고, 세션 이벤트는 gpui `cx.spawn` 태스크가
  채널에서 받아 엔티티를 갱신한다.
- 홈 화면
  - "이 기기" 카드: 접속 주소(로컬 IP:포트 목록), 일회용 비밀번호(복사, 새로 만들기, 숨기기),
    호스트 켜기/끄기 스위치, 현재 연결된 뷰어 표시와 연결 끊기 버튼
  - "원격 기기에 접속" 카드: 주소 입력, 비밀번호 입력(마스킹), 접속 버튼, 오류 알림
  - 권한 상태(macOS): 화면 기록·손쉬운 사용 권한이 없으면 안내 배너와 시스템 설정 열기 버튼
- 뷰어 창
  - 디코딩된 BGRA 프레임을 `RenderImage`로 감싸 `img()`로 표시, 비율 유지 맞춤.
    새 프레임이 오면 이전 이미지는 `drop_image`로 GPU 아틀라스에서 해제한다.
  - 마우스 이동/버튼/스크롤, 키 다운/업을 프로토콜 이벤트로 변환 (레터박스 영역 제외,
    창 좌표 → 정규화 좌표)
  - 툴바: 연결 상태, FPS/지연, Ctrl+Alt+Del 대체 전송(Windows 호스트), 수정자 매핑 토글, 연결 끊기
  - 창을 닫으면 세션 종료
- 설정 저장: `directories`로 OS별 설정 경로, `toml`로 직렬화 (포트, 최근 접속 주소, 기기 이름)
- 다국어: 우선 한국어/영어 문자열을 한 모듈에 모은다.

## 작업 항목

- `crates/app` UI 구현 (홈, 뷰어, 설정 저장, 권한 확인)
- 키 매핑 테이블(gpui `Keystroke` → `KeyCode`) 단위 테스트
- 좌표 변환(레터박스 포함) 단위 테스트
- gpui 테스트 창으로 뷰어 프레임 교체 시 이전 이미지 해제 확인

## 완료 조건

- macOS 두 프로세스(또는 macOS↔Windows)로 GUI에서 접속·제어·종료가 동작
- 뷰어 창을 오래 켜 두어도 메모리가 계속 늘지 않음 (프레임 이미지 해제 확인)
