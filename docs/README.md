# open-desk 문서

open-desk는 macOS와 Windows 11이 서로 접속할 수 있는 원격 데스크톱 프로그램입니다. 설치와 기본 사용법은
저장소 [README](../README.md)에 있고, 이 디렉터리에는 그보다 깊은 내용을 모았습니다.

| 문서 | 읽는 사람 | 내용 |
| --- | --- | --- |
| [사용 가이드](user-guide.md) | 사용자 | 화면 구성, 설정 항목, 저장 위치, 문제 해결 |
| [릴레이 서버 운영](relay.md) | 운영자 | 다른 네트워크의 기기를 ID로 연결하는 릴레이 실행과 남용 방지 |
| [아키텍처](architecture.md) | 개발자 | 크레이트 구성, 스레드 모델, 세션 생명주기, 데이터 흐름 |
| [와이어 프로토콜](protocol.md) | 개발자 | 프레이밍, 핸드셰이크·제어·비디오·입력·릴레이 메시지, 상수 |
| [보안 모델](security.md) | 개발자·검토자 | 위협 모델, 인증과 암호화, 남용 방지, 알려진 한계 |
| [개발 가이드](development.md) | 개발자 | 툴체인, 품질 게이트, 테스트 종류, CI, 릴리스 절차 |
| [개발 기록](history.md) | 모두 | phase별 PR, 리뷰에서 찾은 결함과 수정, 검증 현황, 교훈 |
| [구현 계획](plan/README.md) | 개발자 | phase별 설계 원안과 구현 노트(계획과 달라진 점) |

문서는 v0.1.0(2026-10-03) 기준입니다. 코드와 문서가 어긋나면 코드가 기준이며, 상수 값은 각 문서에
적힌 소스 파일에서 확인할 수 있습니다.
